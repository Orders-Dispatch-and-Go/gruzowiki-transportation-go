## Api БД

### расчет маршрута

- Post /routes/cargo_requests
- Post /routes/trips
````
{
    "fromStation": {
        id: uuid, //id станции под которым она сохранена в сервисе грузоперевозок
        address: string,
        coords: {
            lat: float,
            lon: float
        }
    },
    "toStation":  {
        id: uuid,
        address: string,
        coords: {
            lat: float,
            lon: float
        }
    },
}
````

HttpStatus: 200
````
{
    "id": "uuid"
}
````

1. id - идентификатор расчитанного маршрута

## получение маршрута

расчитайте порядок и, если возможно, расстояние между станциями, примерное время 

дистанци и время рассчитывайте так: сколько времени потребуется от предыдущей, 
т.е. у первой станции не будет этих данных, потому что с первой стартуем

если запарно по времени и вы не реализуете расчет времени и дистанцию, то не возвращайте эти поля

обязательно возвращайте станции в порядке следования

- Get /routes/cargo_requests/{uuid}
- Get /routes/trips/{uuid}
````
{
  "stations": [
    {
      "station": {
        address: string,
        coords: {
            lat: float,
            lon: float
        }
      },
      "distance": "int",
      "tripTime": "utc",
    }
  ]
}
````

## получение точек маршрута по идентификатору маршрута

1) Get /routes/cargo_requests/{uuid}/points
2) Get /routes/trips/{uuid}/points
````
{
  "points": [
    [float, float],
    [float, float],
    ...
  ]
}
````

## получение потенциальных маршрутов для поездки

передается маршрут заявки и маршруты поездок, отсортированные по критериям в сервисе грузоперевозок

возвращается список потенциальных поездок, которые потенциально могут исполнить заявку
(поездка по новосибирску может перевезти груз по новосибирску)

Post /routes/trips/potential
````
{
  "tripRouteId": "uuid" // идентификатор маршрута поездки
  "cargoRequestRouteIds": [
    "uuid",
    "uuid",
    ...
  ] // список идентификаторов маршрутов заявок - кандидатов на слияние
}
````

Http status: 200
````
{
  "routeIds": [
    "uuid",
    "uuid",
    ...
  ]
}
````

## слияние маршрутов заявки и поездки

возвращается маршрут

Post /routes/trips/merge
````
{
  "tripRouteId": "uuid",
  "cargoRequestRouteId": [ 
    "uuid",
    "uuid"
  ]
}
````

Http status: 200
````
{
  "routeId": "uuid"
}
````

### удаление заявки из маршрута поездки
Post /routes/trips/cargo_request/remove

изменение состояния маршрута без изменения идентификатора маршрута

для указанной поездки удаляете станции, на которых происходит погрузка и разгрузка заявки, 
пересчитываете маршрут на основе станций которые остались

````
{
  "deleteStationIds": [ 
    "uuid",
    ...
  ],
  "tripId": "uuid"
}
````

Http status: 200
