## Api БД

### расчет маршрута для заявки

рассчитываете маршрут для заявки и сохраняете его к себе в бд

Post /route/cargo_requests

````
{
    "cargoRequest": "uuid",
    "fromStation": {
        address: string,
        coords: {
            lat: float,
            lon: float
        }
    },
    "toStation":  {
        address: string,
        coords: {
            lat: float,
            lon: float
        }
    },
}
````

HttpStatus: 200

````
{
    "id": "uuid"
}
````
1. id - идентификатор расчитанного маршрута

## получение маршрута для заявки

расчитайте порядок и, если возможно, расстояние между станциями, примерное время 

дистанци и время рассчитывайте так: сколько времени потребуется от предыдущей, 
т.е. у первой станции не будет этих данных, потому что с первой стартуем

Get /route/cargo_requests/{uuid}

````
{
  "stations": [
    {
      "station": {
        address: string,
        coords: {
            lat: float,
            lon: float
        }
      },
      "distance": "int",
      "orderNum": "int",
      "tripTime": "utc",
    }
  ]
}
````
